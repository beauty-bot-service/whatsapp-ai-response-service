# BeautyBot Admin Web

Panel React/Vite del catálogo de promociones. Su backend es el servicio Spring Boot ubicado en la raíz del repositorio.

```powershell
npm install
npm run dev
```

El build de producción se genera con `npm run build`. Consultar `docs/PROMOTIONS_ADMIN.md` para la arquitectura, seguridad y configuración de despliegue.
